# 🌐 A* Pathfinding Simulation (Godot Web Build)

This repository hosts an interactive **A\* Pathfinding Simulation** built with the **Godot Engine**, exported for the web using **HTML, JavaScript, and WebAssembly**.  
The project visually demonstrates how the **A\*** (A-star) algorithm searches for the optimal path across a grid.

## 🧠 Overview

A* (A-star) is one of the most popular algorithms in **pathfinding and graph traversal**, commonly used in robotics, games, and route optimization.  
This project provides a **visual representation** of how A* explores possible paths, prioritizing nodes based on **cost (g)** and **heuristic (h)** values.

The web build was generated from a **Godot 4.x** project and includes:
- Compiled runtime files (`.js`, `.wasm`, `.pck`)
- An HTML loader (`index.html`)
- Manifest and service worker for browser support

## ⚙️ How It Works

1. The simulation generates a grid representing walkable and non-walkable cells.  
2. The user selects **start** and **goal** nodes.  
3. The **A\*** algorithm begins exploring neighboring nodes, calculating:
   - **g(n):** cost from start to current node  
   - **h(n):** estimated cost from current node to goal  
   - **f(n) = g(n) + h(n)**  
4. The shortest path is visualized step-by-step in real time.

## 🚀 Running the Simulation

You can try the simulation in two ways:

### Option 1 — Online Demo
Hosted version:  
🔗 [https://alawyyahdan.github.io/astar-sim/](https://alawyyahdan.github.io/astar-sim/)

### Option 2 — Local Run
1. Clone this repository:
   ```bash
   git clone https://github.com/alawyyahdan/astar-sim.git
   cd astar-sim
   ```
2. Launch a local web server (Python example):
   ```bash
   python3 -m http.server 8000
   ```
3. Open your browser and visit:
   ```
   http://localhost:8000
   ```
